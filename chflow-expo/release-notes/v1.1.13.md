# v1.1.13 iOS 업데이트 안내 기능

## 한국어

- iOS에서도 새 버전이 App Store에 공개되면 앱 실행 시와 백그라운드에서 복귀할 때 업데이트 여부를 확인합니다.
- 권장 업데이트는 닫을 수 있는 배너로 안내하고, 필수 업데이트는 업데이트가 완료될 때까지 앱 사용을 제한합니다.
- 업데이트 버튼은 한국 App Store의 스마트명성 페이지로 연결됩니다.
- 업데이트 확인 서버가 응답하지 않거나 올바른 버전 정보를 제공하지 않으면 기존 앱 사용을 허용합니다.

### TestFlight에서 확인할 내용

- 1.1.13을 처음 실행하고 백그라운드에서 복귀해도 현재 공개 버전 설정(1.1.12) 때문에 잘못된 업데이트 안내가 표시되지 않는지 확인해 주세요.
- 로그인, 주요 화면 이동, 출석 및 알림 등 기존 기능이 정상 동작하는지 확인해 주세요.
- 이 업데이트 안내 코드는 1.1.13부터 포함됩니다. 실제 다음 버전 안내 동작은 1.1.14 이상이 App Store에 공개된 뒤 1.1.13 설치 기기에서 확인할 수 있습니다.

## English

- iOS now checks for a newer App Store version when the app launches and when it returns from the background.
- Recommended updates appear as a dismissible banner, while required updates block app use until the update is installed.
- The update button opens the Smart Myungsung page on the Korean App Store.
- If the update service times out or returns invalid version data, the app remains usable.

### What to Test

- Launch version 1.1.13 and return to it from the background. No false update prompt should appear while the published-version setting remains at 1.1.12.
- Verify that sign-in, primary navigation, attendance, and notifications continue to work normally.
- The update-checking code is first included in 1.1.13. The real prompt can be verified on a device running 1.1.13 after version 1.1.14 or later becomes available on the App Store.

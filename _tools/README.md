## avatar-tuner.html — 초등부 기본얼굴 아바타 위치 조정기

내반출결·우리반 아이정보에 쓰는 기본얼굴(일러스트) 15종이 원형 안에서
가운데로 보이도록 좌우/상하/크기를 조정하는 도구.

### 쓰는 법
1. `avatar-tuner.html` 더블클릭 → 브라우저에서 열림 (설치·서버 불필요, 이미지 내장)
2. 각 얼굴의 슬라이더로 조정
   - 빨간 세로선 = 좌우 중앙, 파란 가로선 = 눈높이(42%) 기준
   - **X 좌우**(+오른쪽/−왼쪽), **Y 상하**(+아래/−위), **크기**(확대)
3. 맨 아래 **📋 코드 복사** → 복사된 `FACE_ADJUST { ... }` 블록을
   `chflow-app/lib/kidAvatar.ts` 의 같은 블록에 통째로 붙여넣기
4. commit → push → 약 25초 뒤 Vercel 자동배포 → 앱 Ctrl+Shift+R 로 확인

### 이미지가 추가/교체되면
`avatar-tuner.html` 에는 그 시점 이미지·값이 내장돼 있으므로,
이미지를 바꾸거나 kidAvatar.ts 기본값이 크게 달라지면 재생성:

```
python _tools/make-avatar-tuner.py
```

(스크립트 상단 `CUR` 딕셔너리를 현재 kidAvatar.ts 값과 맞춰두면
도구가 그 값에서 시작합니다.)

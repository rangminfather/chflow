# 부서 홈 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 부서 홈 |
| 대분류 | 사역·부서 메뉴 |
| 간단 설명 | 소속 부서의 공지, 학생관리, 행정관리, 부서관리 메뉴를 등급별로 보여준다. |
| 사용자/권한 | 부서원 |
| 라우트 | /departments/d/[id] |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/departments/d/[id]/page.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 내 사역 진입 | `app/home/page.tsx` | 승인된 내 부서를 누르면 /departments/d/[id]로 이동한다. | 사용자는 자기 부서 업무 화면으로 들어간다. |
| 2 | 등급별 메뉴 표시 | `app/departments/d/[id]/page.tsx` | get_user_grade 결과와 MENU_CATEGORIES의 maxGrade를 비교한다. | 전도사/부장/교사/학부모 등급에 따라 메뉴 노출이 달라진다. |
| 3 | 구현 여부 처리 | `app/departments/d/[id]/page.tsx` | implemented=false 메뉴는 라우팅하지 않고 준비중 토스트를 띄운다. | 미완성 메뉴를 사용자가 오인하지 않게 한다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

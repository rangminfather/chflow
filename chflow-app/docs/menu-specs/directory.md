# 성도 요람 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 성도 요람 |
| 대분류 | 홈 공통 메뉴 |
| 간단 설명 | 이름, 전화번호, 배우자, 목장 기준으로 성도 정보를 조회한다. |
| 사용자/권한 | 인증 사용자 |
| 라우트 | /directory |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/directory/page.tsx`
- `components/MemberCardModal.tsx`
- `components/PhotoAvatar.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 홈 메뉴 진입 | `app/home/page.tsx` | COMMON_MENUS의 성도 요람 카드가 /directory로 이동한다. | 사용자는 홈에서 성도 요람 메뉴를 선택한다. |
| 2 | 인증 및 검색 화면 | `app/directory/page.tsx` | 클라이언트 페이지가 검색 조건과 페이지 상태를 관리한다. | 이름/전화/배우자/목장 등으로 성도 목록을 조회한다. |
| 3 | 상세 보기 | `components/MemberCardModal.tsx` | 선택한 회원 정보를 모달로 보여준다. | 가족/목장/사진 등 회원 상세 정보를 확인한다. |
| 4 | 관리자 연결 | `app/directory/page.tsx` | 관리자 권한이면 회원관리 이동 버튼을 노출한다. | 요람에서 발견한 데이터를 관리자 편집 화면으로 이어갈 수 있다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

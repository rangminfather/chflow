# 내 정보 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 내 정보 |
| 대분류 | 홈 공통 메뉴 |
| 간단 설명 | 내 프로필, 연락처, 사진 등 개인 정보를 확인하고 관리한다. |
| 사용자/권한 | 인증 사용자 |
| 라우트 | /myinfo |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/myinfo/page.tsx`
- `components/PhotoAvatar.tsx`
- `lib/roles.ts`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 홈 메뉴 진입 | `app/home/page.tsx` | COMMON_MENUS의 내 정보 카드가 /myinfo로 이동한다. | 사용자가 본인 정보 관리 화면으로 들어간다. |
| 2 | 프로필 조회 | `app/myinfo/page.tsx` | Supabase RPC/세션 정보를 기반으로 내 정보를 불러온다. | 이름, 전화번호, 직분, 소속 정보 등을 표시한다. |
| 3 | 사진 표시/관리 | `components/PhotoAvatar.tsx` | 프로필 사진과 회원 사진을 표시한다. | 사용자 화면에서 개인 식별성을 높인다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

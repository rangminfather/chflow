# 불편신고/건의 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 불편신고/건의 |
| 대분류 | 홈 공통 메뉴 |
| 간단 설명 | 앱 사용 중 불편사항이나 건의사항을 등록하고 처리 상태를 확인한다. |
| 사용자/권한 | 인증 사용자 |
| 라우트 | /feedback |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/feedback/page.tsx`
- `app/feedback/new/page.tsx`
- `app/feedback/[id]/page.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 목록 조회 | `app/feedback/page.tsx` | 피드백 목록과 상태 필터를 표시한다. | 미접수/접수/검토중/처리완료/처리불가 상태로 관리한다. |
| 2 | 글쓰기 | `app/feedback/new/page.tsx` | 새 피드백 등록 폼을 제공한다. | 사용자가 제목과 내용을 입력해 개선 요청을 남긴다. |
| 3 | 상세 확인 | `app/feedback/[id]/page.tsx` | 선택한 피드백의 상세 내용과 상태를 보여준다. | 처리 흐름을 추적할 수 있다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

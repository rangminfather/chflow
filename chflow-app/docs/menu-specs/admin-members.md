# 회원관리 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 회원관리 |
| 대분류 | 상단 관리자 빠른메뉴 |
| 간단 설명 | 성도 데이터를 검색, 추가, 수정, 삭제하고 관련 운영 메뉴로 이동한다. |
| 사용자/권한 | admin/office/pastor |
| 라우트 | /admin/members |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/admin/members/page.tsx`
- `components/MemberCardModal.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 빠른 진입 | `app/home/page.tsx` | AdminPill 회원관리가 /admin/members로 이동한다. | 관리자 핵심 데이터 관리 화면으로 들어간다. |
| 2 | 회원 CRUD | `app/admin/members/page.tsx` | 검색/상세/추가/수정/삭제 UI를 제공한다. | 성도 기본정보와 가족/목장/주소 등 운영 데이터를 관리한다. |
| 3 | 연관 메뉴 | `app/admin/members/page.tsx` | 부서원 관리, 재편성, 가입 대기자, 운영 상태 버튼을 제공한다. | 회원관리에서 운영 메뉴로 분기한다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

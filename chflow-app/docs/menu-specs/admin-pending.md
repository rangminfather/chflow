# 가입자 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 가입자 |
| 대분류 | 상단 관리자 빠른메뉴 |
| 간단 설명 | 회원가입 신청자를 승인하거나 관리한다. |
| 사용자/권한 | admin/office/pastor |
| 라우트 | /admin/pending |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/admin/pending/page.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 빠른 진입 | `app/home/page.tsx` | AdminPill 가입자가 /admin/pending으로 이동한다. | 관리자가 가입 대기자를 빠르게 확인한다. |
| 2 | 승인 처리 | `app/admin/pending/page.tsx` | 대기 사용자 목록을 조회하고 승인/관리 UI를 제공한다. | 회원가입 이후 활성화 전 상태를 운영자가 처리한다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

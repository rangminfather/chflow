# 부서원 관리 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 부서원 관리 |
| 대분류 | 관리자 연관 메뉴 |
| 간단 설명 | 부서 소속 회원과 등급을 관리한다. |
| 사용자/권한 | admin/office/pastor |
| 라우트 | /admin/dept-staff |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/admin/members/page.tsx`
- `app/admin/dept-staff/page.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 회원관리 내 이동 | `app/admin/members/page.tsx` | 회원관리 상단 버튼에서 /admin/dept-staff로 이동한다. | 부서 권한/등급 관리로 분기한다. |
| 2 | 부서원 등급 | `app/admin/dept-staff/page.tsx` | 부서원 상태와 등급 메타를 표시한다. | 전도사/부장/교사/학부모 권한 체계를 관리한다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

# 차량 신청 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 차량 신청 |
| 대분류 | 관리자 메뉴 |
| 간단 설명 | 교회 차량 신청 |
| 사용자/권한 | 관리자 중심 예정 메뉴 |
| 라우트 | (미연결) |
| 구현상태 | 준비중 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 메뉴 카드 | `app/home/page.tsx` | ADMIN_EXTRA_MENUS에는 정의되어 있으나 href가 없다. | 클릭 시 준비중 알림만 표시된다. 상세 기능은 아직 구현되지 않았다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.
- 비고: ADMIN_EXTRA_MENUS에 카드만 있고 href가 없어 준비중 alert 표시

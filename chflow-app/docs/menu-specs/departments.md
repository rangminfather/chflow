# 사역·부서 가입 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 사역·부서 가입 |
| 대분류 | 사역·부서 메뉴 |
| 간단 설명 | 사용자가 가입 가능한 사역/부서 카테고리와 부서 목록을 탐색한다. |
| 사용자/권한 | 인증 사용자 |
| 라우트 | /departments, /departments/[category] |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/departments/page.tsx`
- `app/departments/[category]/page.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 홈/내 사역 진입 | `app/home/page.tsx` | 내 사역·부서 섹션에서 /departments로 이동한다. | 사용자가 소속 부서가 없거나 추가 가입이 필요할 때 진입한다. |
| 2 | 카테고리 목록 | `app/departments/page.tsx` | 부서 카테고리를 표시하고 선택 시 category 라우트로 이동한다. | 교육/봉사 등 부서 영역별 탐색을 제공한다. |
| 3 | 부서 목록 | `app/departments/[category]/page.tsx` | 선택한 카테고리의 부서 목록과 가입 상태를 표시한다. | 가입됨/승인대기/거절 등 상태를 확인한다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.

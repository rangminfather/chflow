# 투표 기능정의서

## 1. 메뉴 정의

| 항목 | 정의 |
|---|---|
| 메뉴명 | 투표 |
| 대분류 | 관리자 메뉴 |
| 간단 설명 | 진행 중인 투표 참여와 관리자 투표 관리를 한 메뉴 흐름으로 통합한다. |
| 사용자/권한 | admin/office/pastor 및 투표 대상 사용자 |
| 라우트 | /vote, /admin/votes |
| 구현상태 | 구현 |
| 기준일 | 2026-06-05 |

## 2. 관련 파일

- `app/home/page.tsx`
- `app/vote/page.tsx`
- `app/vote/[id]/page.tsx`
- `app/admin/votes/page.tsx`

## 3. 기능 목록

| 연번 | 내용 | 해당파일 | 동작원리 | 기능상세설명 |
|---:|---|---|---|---|
| 1 | 홈 메뉴 진입 | `app/home/page.tsx` | 관리자 메뉴의 투표 카드가 /vote로 이동한다. | 투표 도메인의 대표 진입점을 /vote로 통일한다. |
| 2 | 투표 목록 | `app/vote/page.tsx` | get_active_votes RPC로 진행 중인 투표를 조회한다. | 사용자는 참여 가능한 투표 목록과 완료 여부를 본다. |
| 3 | 투표 참여 | `app/vote/[id]/page.tsx` | get_vote_detail/cast_vote RPC로 후보 조회와 투표 제출을 수행한다. | 중복 투표를 막고 투표 기간/활성 상태를 검사한다. |
| 4 | 투표 관리 | `app/admin/votes/page.tsx` | admin_get_votes 및 admin_* RPC로 투표 생성, 후보, 결과를 관리한다. | 관리자는 같은 투표 메뉴에서 생성/수정/삭제/결과 확인을 수행한다. |

## 4. 유지보수 포인트

- 메뉴명/설명 변경은 먼저 진입점 파일을 확인한다.
- 라우트가 있는 메뉴는 해당 page 파일과 연결 API/RPC를 함께 점검한다.
- 권한 문제가 발생하면 홈 메뉴 노출 조건, 페이지 인증 로직, Supabase RLS/RPC 권한을 순서대로 확인한다.
- 비고: 상단 투표관리 버튼은 제거되고 /vote 안에 관리자 관리 버튼이 표시됨

# 위치 기반 자동출석 1단계 설계

## 목적

성도용 자동출석은 교회 근처 체류를 목회 참고용 신호로 기록한다. 법적 증빙이나 예배 참여의 확정 판정이 아니다.

## 판정 흐름

1. 모바일 OS가 교회 geofence 진입을 감지한다.
2. 앱이 `attendance_location_candidates`에 하루 1건의 후보를 제출한다.
3. 교회 반경 안에서 설정된 최소 체류시간(기본 10분)을 충족하면 서버 RPC가 `church_attendance`에 `auto_geofence` 기록을 만든다.
4. 같은 성도·같은 날짜는 unique 제약으로 중복 기록하지 않는다.

## 기본 정책

- 반경: 150m (관리자가 50~500m 범위에서 변경)
- 활동 시간: 07:00~15:00, `Asia/Seoul`
- 최소 체류: 600초(10분)
- 저장 위치정보: 원시 좌표는 저장하지 않고 거리·정확도·시간·OS 이벤트 출처만 저장
- 수동 출석과 자동 출석은 같은 날짜에 하나의 기록으로 합쳐지며, 자동출석은 참고용으로 표시

## 권한

- 성도: 본인의 후보/출석만 조회, 모바일 RPC로 후보 제출
- 목사·교역/사무 권한·관리자 및 목자/목녀: 소속 성도의 후보/출석 조회
- 위치 설정 변경: 관리자·사무 권한
